## 演示一：商品目录优化

1. 使用 `analyst` 登录。
2. 新建会话“商品目录优化”。
3. 上传 `sample_data/scenario_a/category_master.csv`。
4. 发送：

```text
请分析最近 30 天商品目录优化问题。重点检查高曝光低点击类目、类目属性完整度与转化变化，并给出下一步动作。
```

5. 在实时任务区依次展示：
   - 场景识别；
   - 安全命令白名单执行；
   - 类目聚合 SQL；
   - JSON 中间文件写入和回读；
   - 文本检索；
   - 结果文件生成。
6. 展示结果：
   - 总曝光量；
   - 整体点击率；
   - 整体点击到下单转化率；
   - 低效类目曝光占比；
   - 样例 GMV；
   - 家居收纳、办公文具、美妆个护证据；
   - 四条后续建议。
7. 点击导出并打开 Markdown 文件。
8. 在同一会话追问：

```text
请进一步区分价格问题和类目属性问题，并给出验证实验设计。
```

9. 展示系统生成第二轮任务和独立结果文件。

## 演示二：客户行为分析

1. 新建会话“客户行为漏斗”。
2. 上传 `sample_data/scenario_b/visit_events.csv`。
3. 发送：

```text
请分析最近 30 天客户行为漏斗，定位访问到加购、加购到下单的主要流失环节和用户分群差异。
```

4. 展示工具执行：
   - 渠道、城市、访问、加购、订单聚合 SQL；
   - `customer_funnel.json` 写入；
   - 文件回读校验；
   - 客户转化漏斗文本检索。
5. 展示结果：
   - 访问用户数；
   - 访问到加购率；
   - 加购到下单率；
   - 访问到下单率；
   - 待优化分群数；
   - 社交/北京和自然流量/上海的证据；
   - 包邮门槛、结算埋点、新老客拆分等建议。
6. 导出结果并展示 `exports/{user_id}/{conversation_id}/task_{task_id}_result.md`。

## 管理员演示

1. 使用 `admin` 登录。
2. 进入“配置”。
3. 将 `analysis.low_ctr_threshold` 从 `0.035` 修改为 `0.04`。
4. 点击“热更新配置”。
5. 重新运行商品目录分析，观察低点击类目范围变化。
6. 进入“日志”，按任务 ID 查看 SQL、工具和状态事件。
